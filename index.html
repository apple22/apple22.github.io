03 / HOW I WORK

코드를 넘어
운영까지 생각합니다.

  1. 01

    업무 흐름을 먼저 이해합니다.

    요구사항을 화면 단위로만 보지 않고 사용자의 업무 순서, 데이터 상태와 예외 조건을 함께 확인합니다.

  2. 02

    연결 구간을 구체적으로 검증합니다.

    화면, 서버, DB, 외부 API 사이에서 요청값과 응답값이 일관되게 처리되는지 점검합니다.

  3. 03

    재현 가능한 방식으로 오류를 해결합니다.

    로그와 통신 결과를 기준으로 오류 조건을 재현하고 원인을 분리해 수정 범위를 좁힙니다.
